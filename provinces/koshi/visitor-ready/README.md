# Koshi Province — Visitor-Ready Tourism Enrichment

Status: COMPLETE province pass (14/14 districts)

## Province model
Koshi stretches from the Everest–Makalu–Kanchenjunga Himalaya through middle-hill Kirat/Limbu cultural landscapes, tea country and the eastern Terai wetlands. Visitor routing is therefore modeled as connected travel systems rather than disconnected pins.

## Mandatory map rules
- protected areas, cities, valleys, tea landscapes, wetlands and large villages: AREA/POLYGON with practical access nodes
- rivers and trekking circuits: CORRIDOR/ROUTE
- temples, museums, monuments, gates, airports and verified viewpoints: POINT only when entrance/visitor coordinate is reliable
- uncertain local sites: HOLD rather than guessed coordinates

## Permit rules
Restricted-area trekking is NOT province-wide. Current Department of Immigration controls apply only to specified wards: Taplejung (Phaktanglung 6–7, Mikwakhola 5, Sirijunga 8), Sankhuwasabha (Bhotkhola 1–5, Makalu 4), and Solukhumbu (Khumbu Pasang Lhamu 5). Store restricted permits separately from conservation/national-park entry and climbing permits. Fees/rules are dynamic and must be refreshed from Immigration before publication.
